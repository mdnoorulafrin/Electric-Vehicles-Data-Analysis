# Electric-Vehicles-Data-Analysis

Excited to share my latest data visualization project on Electric Vehicles using Tableau Public!
In this analysis, I worked with a dataset of over 150,000 EV records, exploring insights like:

Vehicle distribution by model year and state

Top manufacturers and models (Tesla leading the charts!)

CAFV eligibility

Electric range metrics

Challenges faced:

Cleaning and transforming raw data for accurate aggregation

Managing large volumes in Tableau Public with performance considerations

Ensuring clarity in visual storytelling while handling multi-dimensional filters

This project helped me deepen my skills in data modeling, dashboard design, and analytical thinking.
